# 📡 BondChat

> **Aplicativo de Comunicação de Emergência Resiliente (v4.0).**

## 🎯 Desafio Estratégico
Manter a comunicação crítica ativa em cenários de colapso de infraestrutura de rede convencional.

## 💡 Solução de Engenharia
Arquitetura de aplicativo focada em resiliência. Operação com lógica offline-first (P2P), simulação de protocolos de satélite e sistema de identificação descentralizado (BOND ID) para adição de contatos sem dependência de servidores centralizados de telefonia.

## ⚙️ Stack & Funcionalidades
- **Rede:** Simulação de conectividade P2P Offline e Satélite.
- **Identidade:** Geração de BOND ID único (formato: `BOND-XXXX-XXXX`) para privacidade.
- **Perfil:** Gestão de identidade com foto ou inicial, sem dependência de dados pessoais sensíveis.
